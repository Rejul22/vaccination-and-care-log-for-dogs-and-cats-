# Project Statement

## Problem Statement
Pet details, vaccination dates, appointment choices, and medical notes can be kept in different places or
forgotten. This makes it harder to review a pet’s basic care history. The project addresses this by storing a pet
record and its related medical logs in one local database and providing a menu to add or search that information.


## Target Users
- Pet Owners
- Vets
- Vetenary hospitals


## High Level Feature
- Store pets data.
- Access Already stored pets data.
- Can enter doctors slot with time
- choose and book slots of doctors


## Scope
This can make workflow of pets doctor and pet owners easy and flexible.
